# 📝 基于 Gin 框架的 Go 语言博客系统 (Go-Blog-System)

## 📌 项目简介
本项目是一个基于 Go 语言和 Gin 框架开发的前后端分离（或服务端渲染）的博客内容管理系统。采用 GORM 作为 ORM 框架操作 MySQL 数据库，实现了完整的用户鉴权、文章管理、评论交互以及文件上传等核心功能。

## 🛠️ 技术栈
*   **开发语言**：Go (Golang)
*   **Web 框架**：Gin
*   **ORM 框架**：GORM
*   **数据库**：MySQL
*   **安全与鉴权**：JWT (JSON Web Tokens)、Bcrypt (密码哈希加密)

## 🚀 核心功能模块
本系统包含 13 个核心业务功能，划分如下：

1.  **用户模块**
    *   用户注册、登录（JWT 鉴权），登录状态保持。
    *   密码安全：密码均采用 Bcrypt 加密后入库，不存储明文。
    *   个人信息查看与修改。
2.  **文章模块**
    *   文章发布、修改与删除（删除操作带二次确认，防误删）。
    *   文章列表展示（支持分页查询，包含图片、作者、发布时间等）。
    *   文章详情查看（联动展示文章内容及所属评论）。
    *   关键字搜索：支持按文章标题进行模糊搜索。
3.  **互动模块**
    *   评论发布与展示。
    *   评论删除（权限校验：仅限作者本人删除自己的评论）。
4.  **文件模块**
    *   支持图片/文档等文件的上传功能（如封面图上传）。

## 🗂️ 数据库设计
遵循项目的命名规范，数据库表前缀统一使用 `xzl_`。
核心数据表包括：
*   `xzl_users` (用户表)
*   `xzl_articles` (文章表)
*   `xzl_comments` (评论表)
